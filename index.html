Deployment misconfigured

The host is serving the repository root, not the app.

The Next.js application lives in web/. The repository root has no package.json, so framework detection found nothing here and published these files as a static site. That is why paths return 404 — there is no application running. The code is fine; one project setting points at the wrong directory.

Root Directory
web  — not ./
Framework Preset
Next.js  — not Other. web/vercel.json pins this once the root is right.
Then
Redeploy with the build cache disabled. A real build takes roughly half a minute; a four-second build means it is still publishing static files.

Region and framework are committed in web/vercel.json, and the two non-secret environment variables in web/.env.production. DATABASE_URL is the only value that must be set by hand, because it carries a password. Once the app is running, /api/health reports whether it arrived and what Postgres said if it refused.
